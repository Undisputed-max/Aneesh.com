Anarchy

Battle Royale Vehicles Inventory System Multiplayer

A full-scale battle royale featuring last-player-standing gameplay, a shrinking safe zone, looting, and a fleet of drivable vehicles across a large map. Vehicle classes including bikes, cars, and armoured trucks featured distinct handling characteristics, physics, and combat interactions, integrated into the multiplayer gameplay.

My focus: vehicle physics and handling systems, a multiplayer inventory system, and network synchronisation across online sessions. Developed using Unity and C#, with a focus on responsive gameplay, consistent multiplayer state, and performance optimisation.

// My responsibilities
  • Developed custom vehicle physics and handling — vehicle movement, suspension behaviour, steering, torque tuning, and collision response for bikes, cars, and armoured vehicles.
  • Implemented a multiplayer inventory system — item pickup, storage, equipment, weapon switching, and inventory UI synchronised with multiplayer gameplay.
  • Integrated client-server gameplay synchronisation — vehicle movement, player state, weapon state, and inventory updates across multiplayer clients using Photon networking.
  • Worked on the cross-platform build pipeline — Unity build configuration and gameplay compatibility across supported target devices.
  • Developed and iterated the multiplayer UI/UX — health indicators, inventory HUD, vehicle interaction prompts, and gameplay interface elements connected to player and match state.
// System architecture
Vehicles
Custom Vehicle Physics
Implemented vehicle handling in Unity using WheelColliders and Rigidbody physics, with suspension, steering, and torque tuning for different vehicle classes. Photon synchronisation used for networked vehicle movement, with transform interpolation for smoother remote-client movement.
Inventory
Multiplayer Inventory
Developed a modular C# inventory system supporting item pickup, storage, equipment slots, weapon switching, and loot management. Integrated inventory updates with multiplayer gameplay to maintain consistent player inventory state across connected clients.
Networking
Battle Royale Session Management
Implemented Photon session flow covering lobby, map loading, gameplay, and match results. Integrated safe-zone shrink logic and player elimination with multiplayer game-state updates to keep match progression consistent across connected clients.
